# Güvenlik Politikası

## Desteklenen sürümler

Güvenlik düzeltmeleri `main` dalına ve yayımlanmış en güncel sürüme uygulanır.

## Güvenlik açığı bildirme

Bir güvenlik açığı bulursanız herkese açık issue açmayın. Deponun **Security** sekmesindeki **Report a vulnerability** bağlantısını kullanarak özel bir GitHub Security Advisory gönderin:

<https://github.com/Nurettin-Erdogan/ajan-kalkani/security/advisories/new>

Bildirimde mümkünse etkilenen bileşeni, tekrar üretme adımlarını, olası etkiyi ve önerdiğiniz düzeltmeyi paylaşın. İlk değerlendirme en geç 72 saat içinde yapılır; doğrulanan açıklar etki ve istismar edilebilirliğe göre önceliklendirilir.

## Kapsam

Politika motoru, API, denetim izi, demo yüzeyi ve bağımlılık zinciri kapsam içindedir. Gerçek sistemlere ait anahtar, parola veya hassas verileri test amacıyla göndermeyin.
